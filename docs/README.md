# docs/｜納品資料

| ファイル | 内容 | 読む人 |
|---|---|---|
| [operations-manual.md](operations-manual.md) | 運用マニュアル。画面の見かた・毎月の手順・AI コメントの扱い・管理者の操作・困ったとき | 操作者・管理者 |
| [print/monthly-guide-a4.pdf](print/monthly-guide-a4.pdf) | 毎月の手順を A4 片面1枚にまとめた印刷用の手順書（`print/` に元の HTML もある） | 操作者・管理者 |
| [csv-format.md](csv-format.md) | CSV の形式の説明書。必要な列・日付の形式・取り込めないときの直し方 | 操作者・保守担当 |
| [developer-guide.md](developer-guide.md) | 開発者・保守ガイド。手元での動かし方・テスト・CI・トークンの更新・環境変数の一覧（値は書かない）・管理者がいなくなったときの手順 | 開発者・保守担当 |
| images/ | 運用マニュアルと README に使う画面画像（架空のお店とダミーの CSV で撮影） | 資料の一部 |
