# CSV の形式の説明書

売上ダッシュボードに取り込む CSV の作り方と、取り込めなかったときの直し方です。
対象：CSV を用意する操作者・保守担当。

CSV は、表の内容をカンマで区切って並べたファイルです（拡張子は `.csv`）。Excel で開けます。画面での取り込みの手順は [運用マニュアル](operations-manual.md) の第3章にあります。

## 1. 先に知っておくこと

| 項目 | 内容 |
|---|---|
| ファイルの種類 | CSV（拡張子 `.csv`）。1回に1ファイルだけ選べます |
| 文字コード | UTF-8（文字化けしないための文字の決まり。BOM という印が付いていても読めます）。Excel で保存するときは「CSV UTF-8（コンマ区切り）」を選びます |
| ファイルの大きさ | 5MB まで。超えると取り込まれません（月ごとなどに分けて取り込みます） |
| 1行目 | 列名（見出し）の行にします |
| 見本 | 形を試したいときは、同梱のダミー CSV が使えます。本番版の動作確認：`tests/fixtures/lumina-sample-sales.csv`（48行・2025年9〜11月）／デモの見本：`demo/public/sample-sales-demo.csv` |

### CSV を作って取り込む（3ステップ）

| 何をする | どう操作する | OK の目安 |
|---|---|---|
| ① 列名を確かめる | CSV を Excel などで開き、1行目の列名を、次の「2. 必要な列」と見比べる | 8つの列（または別名）がそろっている |
| ② 保存する | Excel なら「名前を付けて保存」→ ファイルの種類を「CSV UTF-8（コンマ区切り）」にする | 拡張子が `.csv` で、5MB 以内 |
| ③ 取り込む | ダッシュボードの「CSVアップロード」で、ファイルをドラッグするか「ファイルを選ぶ」で選ぶ | 「取り込み前の確認」に「○行 成功 / ×行 スキップ」が出る |

## 2. 必要な列

1行目に、次の8つの列を用意します。列の順番は自由です。

| 列名（正式） | 内容 | 入れ方 | 空欄 |
|---|---|---|---|
| `order_date` | 注文日 | `2025-11-03` または `2025/11/03`（月・日は1桁でも可） | 不可 |
| `customer_id` | 顧客ID | 文字列（例：`C001`） | 可（リピート率の計算から外れるだけ） |
| `product_name` | 商品名 | 文字列 | 不可 |
| `category` | カテゴリ | 文字列 | 不可 |
| `sku` | SKU（在庫管理のための商品コード） | 文字列 | 不可 |
| `quantity` | 数量 | 1以上の整数（`2` はOK、`2.0` はNG） | 不可 |
| `revenue` | 売上 | その行の「単価 × 数量」の合計。0以上の整数の円（`7600` や `7600.0` はOK、`7600.5` はNG） | 不可 |
| `cost` | 原価 | その行の数量分の合計。0以上の整数の円 | 不可 |

- 注文日の後ろに時刻が付いていても（例：`2025-11-01 10:00:00 +0900`）、先頭の日付だけを使います
- 実在しない日付（2月30日など）の行は取り込まれません（スキップされます）
- `customer_email`（メールアドレスの列）は読み飛ばし、保存しません。個人情報を入れないためです

## 3. 列名の別名

列名が少し違っても、次の名前（別名）なら自動で読み替えます。Shopify から書き出した CSV の列名は、ほとんどがここに当てはまります。大文字・小文字、前後の空白、空白と `-` と `_` の違いは区別しません（例：`Order Date` は `order_date` と同じ扱い）。

| 正式な列名 | 読み替えられる別名 |
|---|---|
| `order_date` | `created_at`・`date`・注文日・日付 |
| `customer_id` | `customer`・顧客id・顧客 |
| `product_name` | `lineitem_name`・`product`・商品名 |
| `category` | `product_type`・カテゴリ |
| `sku` | `lineitem_sku`・商品コード |
| `quantity` | `lineitem_quantity`・`qty`・数量 |
| `revenue` | `sales`・`total`・売上・金額 |
| `cost` | `cost_of_goods`・原価 |

- `name` の列は読み替えません（Shopify では注文番号のため）
- 一覧にない列は、読み飛ばします（エラーにはなりません）
- 同じ正式名になる列が2つあると、取り込まれません（例：`revenue` と `売上` の両方がある）

## 4. 取り込みのルール

| 状況 | 画面の動き |
|---|---|
| 必要な列が足りない | 取り込まずに止まり、足りない列名を表示します |
| 一部の行だけ形式が違う | その行だけスキップして、残りを取り込めます。「○行 成功 / ×行 スキップ」と表示されます |
| 1つの CSV に複数の月がある | 月ごとに分けて保存します（本番版の動作確認用のダミー CSV は3か月分） |
| すでにある月が含まれる | 「上書きしますか？」と確認が出ます。「上書きしない」を選ぶと、そのCSV全体を取り込みません（月ごとの部分取り込みはしません） |
| 全行がスキップになる | 取り込まれません。列名と日付・数字の形式を確かめます |

スキップした行は、次の手順で受け取って直せます。

| 何をする | どう操作する | OK の目安 |
|---|---|---|
| スキップした行を受け取る | 「取り込み前の確認」で「スキップ行をダウンロード」を押す | 元の行番号と「理由」の列が付いた CSV が保存される |
| 直す | 理由を見て、元の CSV の該当の行（または列名）を直す | 理由に書かれた点が直っている |
| 取り込み直す | 直した CSV をもう一度選ぶ | 「スキップ」が 0 行になる（または減る） |

## 5. 取り込めなかったとき

| 表示 | 原因 | 直し方 |
|---|---|---|
| 必須の列が見つかりません | 列名が別名の一覧にない | 1行目の列名を、「2. 必要な列」の名前に直す |
| 列名が重複しています | 同じ意味の列が2つある | 片方の列を消す |
| 取り込める行がありませんでした | 全行が形式エラー | スキップ行をダウンロードして理由を見る。列名のずれ（別名にない名前）が多い |
| ファイルが大きすぎます | 5MB を超えている | 月ごとなどに分ける |
| 金額が整数ではありません（スキップ理由） | 円未満の端数がある | 整数の円にそろえる |
| 数値ではありません／大きすぎます（スキップ理由） | 数量・金額に文字が混ざる、または値が極端に大きい | 数字だけにする |

## 6. 取り込み後の数字の見方

- 売上は `revenue` の合計、粗利は `revenue − cost` の合計です
- リピート率（期間全体）は、2か月以上にわたって購入した顧客 ÷ 全顧客です。`customer_id` が空欄の行は含めません

取り込んだ数字が元の CSV と合っているかは、次の手順で確かめられます。

| 何をする | どう操作する | OK の目安 |
|---|---|---|
| 元の数字を出す | お手元の CSV を Excel で開き、1つの月について `revenue` の列を合計する（`cost` も同じ） | 月の売上と原価の合計が分かる |
| ダッシュボードと見比べる | 取り込んだ後、ダッシュボードで同じ月を選び、売上・粗利（売上 − 原価）のカードを見る | Excel の合計と、カードの売上・粗利が同じ（合えば、正しく読めています） |
| リピート率も確かめる | 同じ CSV で `customer_id` の種類を数え、2か月以上にわたって出てくる顧客の数を割る | 「期間全体」のリピート率と、小数点第1位まで合う |

本番版の動作確認用のダミー CSV（`tests/fixtures/lumina-sample-sales.csv`）で試すと、売上は9月 95,500 円・10月 92,000 円・11月 253,500 円、リピート率の「期間全体」は 40.0%（25人中10人）になります。

デモ版のボタン「ダミーCSVで試す」（画面の表示と同じ名前）で読み込むのは別のファイル（デモの見本：`demo/public/sample-sales-demo.csv`）で、数字も違います。
